# 핵심적인 파일모듈들의 구조
  
  일단 레포를 보면 알겠지만 영어로 학습하는데 특화되어 있는 V1 트랜스포머 아키텍쳐 하나랑 한국어로 학습하는데 특화되어 있는 V2 트랜스포머 아키텍쳐 하나가 있는 것을 알 수 있다.
  
  사실 둘은 구조 자체는 차이가 많이 나지는 않지만 V2 의 V1과의 차이점을 굳이 말하자면 학습을 할 때 나누는 토크나이저가 서로 다르다는 점이다.
  
  V1은 원래 영어를 인식하기 위해 만들어진 트랜스포머이기 때문에 문자별로 "A","p","p","l","e"이런 식으로 쪼개도 상관이 없었지만 V2에서는 한국어를 학습해야 되기 때문에 텍스트를 바이트로 바꾼 다음, 학습데이터에서 자주 등장하는 조합을 합쳐서 단어 별로 토큰을 쪼갤 수 있게 여지를 남겨 두었다는 차이가 있다.
  
  그럼 이제 전체적인 파일 구조를 V1기준으로 하나하나 설명하면서 같이 트랜스포머 구조를 공부해보자
  
 일단 feature/korean-transformer-v2 브랜치 기준으로 핵심적인 파일모듈들의 구조를 보면 다음과 같다.
 
``` 
Transformer/
│
├── model/                     # [A] Transformer 핵심 아키텍처
│   ├── __init__.py
│   ├── embedding.py
│   ├── attention.py
│   ├── feedforward.py
│   ├── transformer_block.py
│   └── gpt.py
│
├── korean_transformer_v2/     # [D] 한국어 V2 시스템
│   ├── __init__.py
│   ├── __main__.py
│   ├── tokenizer.py
│   ├── data_loader.py
│   ├── preprocessing.py
│   ├── model.py
│   ├── optimization.py
│   ├── scheduler.py
│   ├── pipeline.py
│   ├── checkpoint.py
│   └── inference.py
│
└── tests/                     # [F] 테스트 코드
    ├── test_attention.py
    ├── test_model.py
    ├── test_tokenizer.py
    ├── test_training.py
    ├── test_checkpoint.py
    ├── test_dataset_loader.py
    ├── test_model_manager.py
    └── test_v2_*.py

  ```
  
   처음 보면 뭐가 많아 보이고 굉장히 복잡해 보이지만 모듈별로 설명하면 보이는 것보다 쉽다! 하나하나 뜯어보자.
  
  
  ## (1). model/
  파일에서 트랜스포머의 연산부분을 담당하는 모듈이다.
  트랜스포머의 구조를 직접 연산하는 모듈이기 때문에 아주 중요한 역할을 하고 있는 모듈이라고 할 수 있다.
  
  ### [1]. _\_init__.py
  다른 클래스나 기능들을 쉽게 다른 파일에서 쉽게 가져올 수 있게 모듈들을 관리해주는 역할을 하는 코드이다.
  
  클래스 내에서 맨 처음에 작성해야 되는 init함수에서 처음에 필요한 생성자들을 선언해주는 것과 비슷한 느낌이다.
  
  다른 모듈에서도 같은 용도로 사용하기 때문에 다른 모듈을 설명할 때는 이 코드에 대한 설명은 생략하도록 하겠다.
  
  ### [2]. embedding.py
  입력된 토큰을 벡터로 변환시켜주고, 위치 정보를 추가해주는 말 그대로 임베딩을 해주는 역할을 하는 코드이다.
  
  임베딩이란 입력값을 벡터로 변환시켜주는 과정인데 그 임베딩을 수행하는 코드라고 생각하면 편하다.
  
  ### [3]. attention.py
  토큰 사이의 관계를 계산하고, 문맥상 어떤 토큰의 정보를 중요하게 참고할지 결정하는 역할을 하는 코드이다.

전 벨로그에서 설명했었던 attention을 실제로 사용하고, 실행하는 부분이다.
  ### [4]. feedforward.py
 
 토큰의 정보를 가공하는 역할이다. attention으로 문맥 정보가 반영된 각 토큰의 벡터를 비선형적으로 변환하고, 이를 통해 모델이 더 복잡한 패턴을 학습 할 수 있도록 한다.
 
 말이 엄청 복잡해 보이는데 쉽게 설명하면 토큰 사이의 교환되는 정보들을 각 토큰 별로 가공하는 과정이라고 생각하면 편하다.
 
 트랜스포머 모델 구조 그림에서 나오는 FeedForward와 같은 기능을 한다고 생각하면 된다.
 
 ### [5]. Transformer_Block.py
 앞서 만들었던 attention 모듈과 Feed Forward 모듈을 사용해 토큰 간의 관계의 정보와 각 토큰별로 가공한 반영된 정보들을 추가로 변환하고, 이 과정을 하나의 블록으로 보고 여러개의 블록을 쌓고, 이런 과정을 반복하면서 하나의 단위처럼 작용한다.
 
 ### [6]. gpt.py
 앞서 설명 했었던 코드로 구현한 모듈들을 하나로 결합해서 완전한 언어 모델을 만드는 역할을 하는 코드이다.
 
 아는 사람도 있겠지만 gpt는 트랜스포머 모델에서 디코더 부분 구조만 사용하고 있다. 
 
 이 코드도 마찬가지로 트랜스포머의 디코더 부분 구조만 사용하고 있으므로 gpt구조를 사용했다고 할 수 있는데, 내 생각에는 ai가 이 이유 때문에 모듈이름을 "gpt.py" 라고 지은 것 같기도 하다.
 
 ## (2). korean_transformer_v2/
 사실 해당 아키텍처는 앞서 말했던 **model/**에 있는 구조만 써도 트랜스포머적 관점으로 보았을 때는 학습을 하는데 지장이 없다. **model/**모듈에 모든 트랜스포머 아키텍처 구조가 들어있기 때문이다. 하지만 브랜치로 추가한 V2는 조금더 효율적으로 한국어를 학습하는데 특화되게 구조를 만들었다.
 
 V2는 새롭게 아키텍처 구조를 짠 것이 아닌 전에 있던 V1의 구조를 그대로 사용하고 부가적인 구조를 추가로 만들어서 구성했다.
 
 이 **korean_transformer_v2/**의 모듈은 기존에 V1에는 없는 모듈인 부가적으로 추가한 한국어 학습 구조 모듈이다.
 
 서론에서 말했던 기능을 구현하는 모듈이라고 생각하면 된다.
 
 ### [1]. tokenizer.py
 입력 문장을 토큰 별로 처음에 나누어 주는 코드이다.
 
 ### [2]. data_loader.py
 
 데이터 로더, 직역하면 데이터를 불러와주는 장치라고 쉽게 유추 할 수 있다.
 
### [3]. preprocessing.py

학습에 사용할 데이터를 정리하는 데이터 전처리 역할을 하는 코드이다.

불필요한 공백이나 중복된 데이터를 제거하고, 학습용 데이터와 검증용 데이터를 분리하는 역할을 한다.

### [4]. corpus.py

대규모 학습 데이터를 효율적으로 관리하는 역할을 하는 코드이다.

데이터를 전부 메모리에 올리지 않고 디스크에 저장해 필요한 만큼 사용하며, 전처리된 데이터를 캐시로 보관해 재사용할 수 있도록 한다.

### [5]. model.py

V2에서 사용할 Transformer 모델을 설정하고 생성하는 역할을 하는 코드이다.

기존 model/의 아키텍처를 가져와 임베딩 차원, Attention Head 수, Transformer Block 수 등의 하이퍼파라미터를 적용한다.

### [6]. optimization.py

모델의 학습을 효율적이고 안정적으로 진행하도록 최적화하는 역할을 하는 코드이다.

Mixed Precision, Gradient Accumulation, Gradient Clipping 등을 사용해 GPU 메모리 사용과 학습 과정을 최적화한다.

### [7]. scheduler.py

학습 과정에서 Learning Rate(학습률)를 조절하는 역할을 하는 코드이다.

Warmup으로 초기 학습률을 점진적으로 높이고, Cosine Decay를 통해 이후 학습률을 낮춰 안정적인 학습을 돕는다.

### [8]. pipeline.py

V2의 전체 학습 과정을 관리하는 핵심 코드이다.

데이터 전처리부터 토큰화, 모델 생성, Loss 계산, 역전파, 가중치 업데이트까지 여러 모듈을 연결해 실제 학습을 진행한다.

### [9]. checkpoint.py

학습 중인 모델의 상태를 저장하고 복원하는 역할을 하는 코드이다.

모델의 가중치와 Optimizer 상태, 학습 진행 Step 등을 저장해 학습이 중단되더라도 이어서 진행할 수 있도록 한다.

### [10]. inference.py

학습된 Transformer를 이용해 실제 한국어 문장을 생성하는 역할을 하는 코드이다.

입력된 문장을 바탕으로 다음 토큰을 하나씩 예측하고 추가하는 과정을 반복해 새로운 문장을 생성한다.
